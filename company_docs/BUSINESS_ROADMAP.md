# 🚀 BARA AI - 0→1,000명 성장 로드맵 (Business Roadmap)

## 📊 목표: 12개월 내 유료 중개사 1,000명 + 매출 3억 달성

---

## 🗓️ 1단계: 기반 구축 (Month 1-3)
* **목표**: MVP 완성 및 베타 테스터 50명 확보
* **핵심 활동**:
    *   법인 설립 및 사업자 등록
    *   앱(MVP) 런칭: 저평가 분석 + 휴대폰 인증 도입
    *   초기 데이터 확보: 대치동/강남권 주요 매물 DB 구축
* **예산**: 5,000만원 (개발비, 법무비, 초기 서버비)
* **인력**: CEO, CTO, ML 엔지니어 (3명)

## 🗓️ 2단계: 시장 검증 (Month 4-6)
* **목표**: 유료 전환 모델 테스트 및 사용자 300명
* **핵심 활동**:
    *   **자동 광고 시스템** 오픈 (숏츠 생성 기능) -> 킬러 기능으로 유인
    *   유튜브/SNS 마케팅 시작 ("AI가 찾아주는 급매물" 콘텐츠)
    *   첫 유료화 모델 적용 (Basic 멤버십 월 5만원)
* **예산**: 1억원 (마케팅비 증액, 운영 인력 충원)
* **인력**: 마케팅 1명, 운영 1명 추가 (총 5명)

## 🗓️ 3단계: 확장 및 고도화 (Month 7-12)
* **목표**: 사용자 1,000명 돌파, 월 매출 3,000만원+
* **핵심 활동**:
    *   서비스 지역 확장 (강남 -> 서울 전역)
    *   **AI 매칭 고도화**: 계약 성공률 데이터 기반 모델 업데이트
    *   B2B 제휴 (이사, 인테리어 업체 연계 수익 모델)
* **예산**: 2억원 (본격적인 광고 집행, 영업 조직 구축)
* **인력**: 영업팀 2명, 개발팀 2명 추가 (총 9명)

---

## 💰 예산 및 자금 계획 (총 3.5억원)
| 항목 | 금액 | 비고 |
| :--- | :--- | :--- |
| **인건비** | 2억원 | 초기 멤버 및 추가 채용 (1년 치) |
| **개발/서버** | 5,000만원 | 클라우드 비용, API 사용료 |
| **마케팅** | 7,000만원 | 유튜브/SNS 광고, 오프라인 영업 |
| **운영/예비비** | 3,000만원 | 사무실, 법무/특허 비용 |

## 👥 인력 채용 계획
1.  **CEO (대표)**: 비전 제시, 투자 유치, 영업 총괄
2.  **CTO (기술)**: 전체 시스템 아키텍처, 보안 총괄
3.  **ML Engineer**: 저평가/매칭 모델 개발 및 고도화
4.  **Backend Dev**: 서버, API, DB 관리
5.  **Marketing**: 콘텐츠 제작, 퍼포먼스 마케팅
